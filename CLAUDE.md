@AGENTS.md

Revelo es una aplicación web para crear álbumes de fotos online y compartirlos mediante un enlace público de solo lectura. Cada usuario registra una cuenta, organiza sus fotos en álbumes privados y genera un link único para compartir cada álbum con quien quiera, sin que el destinatario necesite crear cuenta.
El nombre juega con el doble sentido de "revelar": revelar fotografías (como en el proceso analógico) y revelar momentos a las personas con las que se comparten.
